## Как это работает

1. **Сбор** — прокси из Telegram-каналов и топиков.
2. **Проверка** — TCP ping, Telethon-подключение, probe resistance (Fake-TLS).
3. **Публикация** — этот репозиторий, Telegram-канал и сайт.

Сортировка по пингу и рейтингу.
